Person A — Data:
  - Cells 1-6 from Claude's data-loading walkthrough -> ETT data loaded
  - Add: train/val/test split per paper (rows 0-8640 / 8640-11520 / 11520-14400)
  - Add: per-channel z-score normalization fit ONLY on train split
  - Test loading end-to-end. Don't wrap in Dataset class yet (Sunday).

Person B — Model:
  - Write src/model.py skeleton. Components in order:
    1. Patching module (uses tensor.unfold)
    2. nn.Linear projection + learnable position embedding
    3. PyTorch's built-in nn.TransformerEncoder (don't write attention from scratch)
    4. Flatten + linear forecast head
  - Smoke test: feed torch.randn(8, 7, 336), verify output shape (8, 7, 96).
  - No real data yet.

Person C — Training scaffolding:
  - Read paper Section 4.1 (datasets, baselines, setup) and Appendix A.1.4
    (model hyperparameters)
  - Write src/train.py skeleton: argparse for hyperparameters, training loop,
    MSE/MAE evaluation, save checkpoints to Drive, log to CSV
  - Use dummy model (nn.Linear(336*7, 96*7)) and dummy data so loop runs
    end-to-end before B and A are ready
  - Start poster skeleton in PowerPoint or LaTeX (empty boxes with section
    titles, content filled later)

End-of-day sync (~6pm, 30 min):
  - A: data loaded + plotted
  - B: model returns correct shape on dummy input
  - C: training loop runs on dummy model

--------------------------------------------------------------------------------
SUNDAY, MAY 3 (~6 hrs)
--------------------------------------------------------------------------------

Person A — Real DataLoader:
  - Wrap data into a PyTorch Dataset class with __len__ and __getitem__
  - __getitem__(i) returns one (look_back, forecast) pair as torch.Tensor with
    shapes (7, 336) and (7, 96)
  - Wrap with DataLoader(batch_size=128, shuffle=True for train, num_workers=2)
  - Add RevIN (instance normalization): subtract mean / divide by std per sample,
    save stats to add back later

Person B — Polish model:
  - Add RevIN denormalization at the output (apply saved stats from A's data)
  - Add channel-independence reshape: (B, M, L) -> (B*M, L) before patching
  - Match paper hyperparameters from Appendix A.1.4:
      D = 128
      H = 16 heads
      3 encoder layers
      dropout 0.2

Person C — Wire it together + first training run:
  - Replace dummy model with B's model.py, replace dummy data with A's dataset.py
  - First real training: ETTh1, L=336, T=96, 100 epochs (early stopping),
    batch=128, Adam lr=1e-4
  - Should take ~10-20 min on T4
  - Target: MSE around 0.370 on test set. Within 10% counts as reproduction.
  - If MSE is wildly off (e.g., > 0.5), debug Sunday night as a team

End-of-day sync (~8pm, 30 min):
  - Baseline numbers in hand, or clear list of bugs to fix Monday morning
